# garjia's Personal Homepage

A modern, responsive personal homepage featuring bilingual support (English & Chinese).

## Features

- ✨ **Modern Design** - Clean and professional UI with gradient backgrounds
- 📱 **Fully Responsive** - Optimized for desktop, tablet, and mobile devices
- 🌍 **Bilingual Support** - English and Chinese versions with easy language switching
- ⚡ **High Performance** - Optimized HTML/CSS with minimal dependencies
- 🔗 **Direct Links** - Fast access to social media and portfolio platforms
- ♿ **Accessible** - Semantic HTML and proper meta tags for SEO

## Pages

- **index.html** - Language selection homepage
- **en.html** - English version with links to Bilibili and CodeMao
- **ch.html** - Chinese version with links to Bilibili and CodeMao

## Quick Start

Simply open `index.html` in your browser or visit the live site at [jia6261.github.io](https://jia6261.github.io)
